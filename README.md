# VITAL-Q reproducibility package

Code, retained inputs and executed records for the VITAL-Q latency study: predicting
verification latency for post-quantum archival evidence. The package replays the published
numerical results from the retained observations, re-verifies the 486 retained selective
proofs under their enrollment policies and can run a fresh full-scale measurement campaign on
the executor's own machine.

## Contents

| Directory | What it holds |
| --- | --- |
| `src/release/` | the original 25-file frozen release (code, configuration, fitted artifacts); `REFERENCE_SHA256.json` fixes its bytes |
| `src/replay_checks.py`, `src/make_figures.py` | numerical replay and figure code |
| `data/published/` | measured rows, saved analyses, audit records and all retained proofs |
| `native/` | Linux x86-64 liboqs library, headers, build receipt and license |
| `scripts/` | portable orchestration, history journal and local checkpoint adapter |
| `notebooks/` | `Reproduce.ipynb` (control notebook) and the original executed analysis notebook |
| `executions/full_scale_20261012/` | a completed full-scale run: 162 histories, 864 development and 1,080 evaluation measurements |
| `validation/` | the checks performed while preparing this package and their limits |

## Quick start (Linux, Python 3.12)

```bash
bash setup.sh          # creates .venv and installs the pinned requirements
bash run.sh replay     # replays the published results from the retained observations
bash run.sh verify     # re-verifies the 486 retained proofs
bash run.sh fresh      # new full-scale campaign on this machine (several hours, 10 GB free)
```

Outputs go to a timestamped directory under `runs/`. Replay needs no network after setup;
cryptographic modes need liboqs (bundled for Linux x86-64; otherwise `bash setup.sh full --build-native`).
A Dockerfile builds liboqs from the pinned commit for other platforms.

## Status of the included full-scale run

Fresh median prediction error was 2.12% (balanced mode) and 2.21% (isolated mode); all 18
point estimates per mode met the ±15% tolerance; 95% interval passes were 17/18 and 16/18.
Details, environment and the disclosed initial cleanup failure are in
`validation/FULL_SCALE_EXECUTION.md`. These measurements are additional reproducibility
evidence; the paper's results are unchanged.

The primary workloads are synthetic and generated by the included code; no external dataset
is needed. Manuscripts and reviewer responses are not part of this repository.
